# Library Management Website

A responsive web application developed as part of a Web Technologies module. 
The project includes a personal CV page, weather data visualisation, an administrator login system, and a library publication management system.

## Features
Responsive website design,
CV and portfolio page,
Weather forecast visualisation using Chart.js,
Administrator login system,
Session-based authentication,
Publication submission system,
Publication listing and viewing,
File-based data storage

## Technologies Used
HTML5,
CSS3,
JavaScript,
PHP

## Project Overview
This project combines several web development components into a single website with a consistent layout and navigation structure. 
Users can view the CV page and weather visualisation directly, while administrators can access additional publication management features through the PHP-based login system.

## Setup
The HTML, CSS and JavaScript pages can be viewed directly in a browser.

The PHP functionality requires a PHP-enabled web server environment to run locally. 
Some features may not function correctly when opened as static files.

## Notes
This repository is intended to showcase the source code and web development techniques used throughout the project. The original project was developed in a university server environment and is included here for portfolio purposes.
